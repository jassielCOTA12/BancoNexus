# Banco Nexus

## Instalación
1. Instalar Node.js
2. Instalar MongoDB

## Ejecución
1. brew services start mongodb-community
2. npm run dev

## Funcionalidades
- Consulta de cuenta
- Depósito
- Retiro
- Visualización de datos

## Arquitectura
React → Node.js → MongoDB

## Problemas encontrados
- Error de conexión MongoDB
- Solución: iniciar servicio
